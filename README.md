# ConsoleBankApp 🏦

A **Java console-based banking application** that implements core banking functionalities such as account creation, deposits, withdrawals, transfers, and transaction tracking using a clean, layered architecture.

This project focuses on **Core Java fundamentals**, clean code practices, and separation of concerns.

---

## 🚀 Features

- Open bank accounts (Savings / Current)
- Deposit money
- Withdraw money
- Transfer funds between accounts
- Maintain transaction history
- List all accounts
- Search accounts by customer
- Robust validation and exception handling
- Menu-driven console interface

---

## 🛠️ Technologies & Concepts Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
- Interfaces & Implementations
- Collections Framework
- Custom Exception Handling
- Layered Architecture
- IntelliJ IDEA
